# 封面作为预览字段（v0.10.0）

## 交互

- 写入选项只保留已有书籍/文字字段范围，不再有“使用哪张封面”“替换哪个封面”。
- 生成预览后，在对应目标下面显示“封面”字段：是否写入的勾选、来源、候选网格、当前图/替换图。
- 默认当前封面、不写图片。选择来源后自动选择该来源第一张，可点击其他候选；取消勾选只取消此目标封面写入。返回选项后重开预览保留当前目标的选择及勾选状态；新搜索清空选择。
- One-shot 只展示一组系列/唯一书籍共用封面。普通系列可在系列与明确选中的书籍下面各选一张，分别写入；不会因作者传播而自动为每本书开启封面选择。
- 所有已选来源保留独立身份。两来源引用同一 URL，两个来源仍可选择；只在各自候选网格内去重。多图片显示网格，可滚动访问全部记录；文字语言不隐藏图片。
- 封面单选，不提供无定义的合并/拼图功能。锁定时不可选，不增加确认框或说明段落。

## 实现与生命周期

`cover-field.ts` 管理一个目标的封面控件、选择、请求与准备好的上传数据。UI 只从启用且已准备完成的字段组装 `Plan.covers`。旧单封面 `Plan.cover` 保留为底层调用兼容；生产 UI 使用数组。Writer 对所有封面先做归属/锁/快照/准备数据预检，再执行元数据和封面写入，保留每目标的成功/失败及撤销记录。

每次选图中止旧请求，过时结果不更新图像；离开预览/关闭弹窗中止请求并回收 Blob URL。预览用统一并发上限 3 的懒加载缩略图队列。实际替换图单独完成下载、MIME/解码校验和快照准备，应用复用看过的同一 Blob，不重新下载。来源选择后图片失败/加载中且仍勾选时，阻止整次应用；就地重试或取消该封面勾选后才能继续。多目标执行中遇到服务端错误仍如实报告部分成功，不宣称原子事务。

## 验收

- 同 URL 的 MU/Baka/AniList 均出现在来源列表；关闭其他/全部文字语言后仍可选。
- 当前图默认不写；选图/取消/返回/重试均保存正确状态。
- 慢请求被新选择覆盖、离开预览取消、锁定禁用、坏图不产生任何写入。
- 普通系列两个目标可同时替换并撤销；One-shot 只上传一次并读回两处显示。
- 真实 Tampermonkey + 公开来源 + 隔离 Komga 验证，不能用缩略图可见代替实际写回。
