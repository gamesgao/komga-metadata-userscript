# 离线目录

离线查询需要预先构建的 SQLite 文件：在目录面板选择文件后，Worker 按页只读访问，
无需把整库加载到内存或复制到 OPFS。显示保留原始标题、作者和命名空间标签。
预制目录清单目前为空；可提供自己的预制文件 URL，下载完成后仍需手动选择文件。

原生构建命令、集成 API、权限及测试范围见
[`catalog/INTEGRATION.md`](../catalog/INTEGRATION.md)。四种来源的导入器目前仅通过
合成小样本验证，完整上游数据的兼容性与资源消耗尚未验收。
高级面板可在支持 OPFS 的安全上下文中用本地来源档案构建，并通过文件保存 API
分块导出；浏览器资源或功能不足时请使用原生 CLI。浏览器内构建同样只经过小样本验证。
