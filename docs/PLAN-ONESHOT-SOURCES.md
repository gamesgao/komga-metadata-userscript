# One-shot 多来源资料与封面支持计划（实现状态见下）

更新：v0.9.2 实现封面保留/排序与 MU 缩略图回退；v0.9.3 实现基于 Komga One-shot 唯一关联书籍的混合来源、目标复核和逐字段取舍，并完成正反选择顺序的真实写回/撤销。普通系列仍保留原层级保护；没有自动同作品识别。下文为原计划，当前验证范围见 VALIDATION.md。

## 已核实的问题

- `merge.ts` 在不知道 Komga 目标的情况下，用 `isVolumeRecord` 禁止系列/单卷混选；`plan.ts` 又将所有 EH 资料直接归为单卷。
- `mergeRecords` 还按文字资料接受语言过滤封面。MangaUpdates 和 EH 的封面适配都未附带封面语言，因此关闭“其他语言”会将它们全部过滤。
- MangaUpdates 搜索卡可使用缩略图，但详情仅采集 `image.url.original`；只有缩略图时会出现卡片有图、封面列表没图的另一条路径。
- 写回规划已有 One-shot 唯一书籍及共享封面逻辑，但此前选择阶段先报错，无法走到这里。

## 修改范围

1. **以 Komga 目标决定写入规则。** `series.oneshot` 且真实关联书籍唯一时，允许系列、单卷、gallery 来源共同参与。普通多书籍系列保留既有目标保护；不能仅凭当前只导入一本就视为 One-shot。
2. **One-shot 不按来源层级/卷号整组拒绝。** 各来源是字段候选，不表示创建/合并多个实体。不新增同作品确认框或提示段落。ISBN、日期等单值由现有逐字段单选处理，标签等多值仍可合并。其他书籍不受影响。
3. **解析目标先于卷号推断。** 先确定 One-shot 的唯一 book，再规划 series/book 适用字段。不能用第一条来源的 provider/volume 决定整个合并结果的写入范围；选择来源先后顺序不改变目标。
4. **封面与文字语言过滤分离。** 保留所有已选条目的有效封面 URL，未知语言不再剔除。语言设置最多决定排序，不使封面消失。MangaUpdates 优先原图、缺失时回退实际可用图片；EH 保留 API 的真实缩略图。按 URL 去重，并保留来源条目关联。
5. **复用现有界面。** 封面下拉显示来源及图片，选后显示实际预览。保留“不修改封面”作为初始选择，不增加说明、开关或额外确认。现有字段语言回退、单选/合并、手动锁保护不变。
6. **复用真实 One-shot 写回。** 元数据按字段写入 series 与唯一 book；封面只上传 book 一次，分别读取 book/series 展示端点验证。下载/解码失败时不写，支持读回与撤销。

## 验收

- 关闭“其他语言”后，已选 MU/EH 的无语言标注封面仍可选；MU 仅有缩略图也可选。
- 同一 One-shot 混选 MU 系列资料与 EH gallery，正反选择顺序均可预览，目标相同。
- 单值来源切换、多值合并以及明确不同卷号来源的字段选择，不被来源层级整组拦截；不拼接 ISBN/日期等单值。
- 真实隔离 Komga + 油猴，使用实际 MU/EH 条目完成混合预览、metadata/cover 写回、双目标读回和撤销；证明锁与其他书籍未变。
- 普通多书籍系列回归，以及封面失败零写入。组件 fixture 与真实公开来源验收分别记录。
