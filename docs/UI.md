# UI 设计与验收

## v0.4.0：搜索进度、本地优先与多来源合并

新增统一来源列表，取消模式切换；旧离线来源勾选迁移到统一列表。可见的结果组提前建立，来源完成后独立更新；进度按已结束来源计数，失败有独立状态，不再等最慢来源才显示全部结果。

选择不同来源的条目形成合并集合，每来源一项；主要来源决定单值优先级，缺项补齐。标签/作者/链接等合并去重，字段规则可以改为仅某来源。人工确认同作品/版本；不同明确卷号、系列与单卷混选会被阻止。预览标注实际字段来源，继续沿用锁检查、读回和撤销。多选时简介折叠以留出写入选项。

目标改名为「同时更新哪本书 / 使用哪张封面 / 替换哪个封面」，显示书名而非内部 ID；作者同步所有书籍是明确选项且默认关闭。移除笼统的能力/未知状态句和作者专属锁提示；锁保护适用于所有字段。

验证：74 核心测试、15 浏览器测试；新增延迟来源的增量进度、来源合并/优先级、锁保护、本地命中零在线调用、本地空结果/失败兜底与取消检查。`acceptance/multi_source.py` 已在真实 GM + 隔离 Komga 完成 Bangumi/MangaBaka 合并预览、写回 GET 核对和撤销；完整本地 Bangumi SQLite 查询/详情及本地无结果转在线均通过。`provider_audit.py` 记录真实来源恢复/受限边界，`real_flows.py` 既有写回/封面/冲突/503 回归通过。原始报告与截图仅在忽略的 `.runtime/acceptance/`。

原生测试环境的 Python Playwright 使用 `uv run --with playwright==1.64.1 python acceptance/multi_source.py`，与已安装 Chromium 156 匹配；无版本约束会取到需要另一套浏览器的新版本。

以下初版章节记录 v0.2.0 基线；最新封面网格与图片预览见末尾 v0.3.0 增量。

## 参考与取舍

查阅搜索结果后，以官方实例/设计说明为参考，而不是复制模板或引入一个前端框架：

- [shadcn/ui Dashboard](https://ui.shadcn.com/examples/dashboard)：中性色、细边框、清晰的卡片与按钮层级、统一间距。
- [Linear — How we redesigned the Linear UI](https://linear.app/now/how-we-redesigned-the-linear-ui)：减少视觉噪声、保持对齐、分清导航与内容、共用亮暗主题变量。该设计说明发表于 2024 年，不将其称作 2026 年新发布的趋势。

保留 TypeScript + 原生 DOM + Shadow DOM。样式、线性 SVG 图标和系统字体在本地打包；不增加 React、远程字体、CSS CDN 或新的运行时服务。既有离线查询的静态 Worker/WASM 加载方式不变。

## 布局与交互

- 居中的原生 modal dialog，清晰标题与当前系列名；背景遮罩仅突出当前操作。
- 「元数据 / 本地数据库 / 设置」页签；数据库管理和凭据不再挤入主表单。
- 主工作区分栏：左侧搜索/来源/结果，右侧目标书籍/封面/字段选择。
- 链接读取和关联单卷按需展开，避免大量按钮与长列表占满首屏。
- 对比预览显示当前值与写入值；标题、简介等字符串直接编辑文本，数组/对象仍用有校验的 JSON 编辑器。保留逐字段取消与返回选项。
- 固定底部操作区。成功仅在写入读回确认后显示绿勾，短暂停留后整窗渐隐；失败保留，成功退出期间不允许重复写入或撤销。
- 亮暗主题切换并通过 GM 存储记忆；首次使用按系统配色选择。
- 820px 以下改为单栏；滚动内容与固定操作区分离。
- 原生模态隔离、明确的输入标签、焦点边界循环、Esc 关闭与返回启动按钮；页签支持左右/Home/End。
- 遵守 reduced-motion：去掉过渡，保留低频的忙碌状态提示。

## 不改变的边界

不改变来源适配、锁保护、写回验证、撤销、认证方式或目录格式。不构建、托管或发布项目方预建数据库；用户仍可导入自己已有的目录或使用本地构建功能。外部数据库下载能力保留为用户自选操作。

## v0.3.0：来源封面网格与图片预览

- 每个来源独立折叠，标题保留来源名、数量或失败状态；原生 `details/summary` 支持鼠标和键盘。在当前面板内保留来源折叠状态。
- 候选以封面卡片呈现，保留标题与完整标题提示；选中后高亮，详情放到右侧，**不清空其他来源和候选**。
- 优先用搜索响应自带图片；缺少图片字段的来源、离线目录按可见候选读取详情补图。最多三个并发图片任务，不为整个结果集一次发出无界请求。
- 图片通过 GM 下载、校验、解码后用 Blob URL 显示，兼容跨域和普通 HTTP；单次搜索按 URL 去重。新搜索或关闭面板取消任务并释放 Blob URL。失败/无图有明确占位，不使用外部假封面。
- 生成预览时先下载并校验新图，再读取当前选中封面；两张图真实解码后显示「当前封面 / 替换为」。目标使用书籍/系列名，不再输出图片 URL 作为预览。
- **应用复用预览中已经显示的同一份 Blob 和 SHA-256，不重新下载来源图。** 图片下载或解码失败时不能应用；不先写元数据再发现图片不可用。服务器上传失败仍保留已有的部分成功/撤销语义。
- 本地通过：66 项核心测试、13 项浏览器测试、6 项 Release 测试、5 组目录测试及两套类型检查。浏览器测试实际检查新旧像素、窄屏、图片消失后仍上传预览字节、404/HTML 阻止写入、来源折叠与 Blob URL 回收。
- 真实 Chromium 156 + Tampermonkey + 隔离 Komga 1.30.0：Bangumi 搜索返回 20 项、MangaBaka 返回 10 项；真实图片显示、来源折叠、选中保留结果和明暗色预览通过。当前测试书封面为 200×300，下载的新图为 637×1000，二者解码后显示。
- `acceptance/real_flows.py` 重新通过真实写回、系列/单本/One-Shot 封面上传读回及撤销、并发冲突、注入 503；测试数据恢复无错误。`acceptance/cover_ui.py` 只读截图，不应用更改。一次登录自动化超时后独立重跑通过，未修改产品绕过登录。
