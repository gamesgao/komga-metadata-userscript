# UI 设计与验收（v0.2.0）

## 参考与取舍

查阅搜索结果后，以官方实例/设计说明为参考，而不是复制模板或引入一个前端框架：

- [shadcn/ui Dashboard](https://ui.shadcn.com/examples/dashboard)：中性色、细边框、清晰的卡片与按钮层级、统一间距。
- [Linear — How we redesigned the Linear UI](https://linear.app/now/how-we-redesigned-the-linear-ui)：减少视觉噪声、保持对齐、分清导航与内容、共用亮暗主题变量。该设计说明发表于 2024 年，不将其称作 2026 年新发布的趋势。

保留 TypeScript + 原生 DOM + Shadow DOM。样式、线性 SVG 图标和系统字体在本地打包；不增加 React、远程字体、CSS CDN 或新的运行时服务。既有离线查询的静态 Worker/WASM 加载方式不变。

## 布局与交互

- 居中的原生 modal dialog，清晰标题与当前系列名；背景遮罩仅突出当前操作。
- 「元数据 / 本地数据库 / 设置」页签；数据库管理和凭据不再挤入主表单。
- 主工作区分栏：左侧搜索/来源/结果，右侧目标书籍/封面/字段选择。
- 链接读取和关联单卷按需展开，避免大量按钮与长列表占满首屏。
- 对比预览显示当前值与写入值；标题、简介等字符串直接编辑文本，数组/对象仍用有校验的 JSON 编辑器。保留逐字段取消与返回选项。
- 固定底部操作区。成功仅在写入读回确认后显示绿勾，短暂停留后整窗渐隐；失败保留，成功退出期间不允许重复写入或撤销。
- 亮暗主题切换并通过 GM 存储记忆；首次使用按系统配色选择。
- 820px 以下改为单栏；滚动内容与固定操作区分离。
- 原生模态隔离、明确的输入标签、焦点边界循环、Esc 关闭与返回启动按钮；页签支持左右/Home/End。
- 遵守 reduced-motion：去掉过渡，保留低频的忙碌状态提示。

## 不改变的边界

不改变来源适配、锁保护、写回验证、撤销、认证方式或目录格式。不构建、托管或发布项目方预建数据库；用户仍可导入自己已有的目录或使用本地构建功能。外部数据库下载能力保留为用户自选操作。

## 本次实际验证

- 本地：62 项核心单测、9 项打包产物浏览器测试、5 组目录测试、两套类型检查。
- 浏览器新增覆盖：亮暗主题持久化；1280/768/390px 布局；原生模态；键盘页签；焦点循环与恢复；预览返回不写入；文本编辑；reduced-motion。
- 既有浏览器回归保留：锁/One-shot/封面/撤销、部分失败、并发冲突、取消、下载回调、非 Komga 页不激活、远端内容安全渲染。
- 动画验证观察真实 busy spinner、成功状态、dialog 的中间 opacity 和最终关闭，不用静态截图代替动画测试。
- 真实 Chromium 156.0.8078.4 + Tampermonkey 5.5 + 隔离 Komga 1.30.0：Bangumi 详情、字段预览、写入读回、系列/单本/One-shot 封面、撤销、并发冲突与注入 HTTP 503 重新通过。仅使用生成的测试书库，未触及用户 NAS。
- `acceptance/ui_capture.py` 使用实际安装的打包脚本、真实公开 Bangumi 数据和实际 Komga 页面截图；只读，不应用更改。复用已有 BookWalker 全量文件核验新数据库页签，未重新构建数据库。
- 该验证不等于所有来源/浏览器已完成验收，认证来源和浏览器内全量构建等既有未验收范围不变。
